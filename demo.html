JavaScript A versatile programming language primarily used for web development, enabling dynamic and interactive webpage functionality.

Created in 1995 by Brendan Eich at Netscape, JavaScript was originally called LiveScript. It quickly became the de‑facto language for client‑side scripting, now powering over 95% of all websites. Interesting facts: it introduced the event‑driven model that made browsers interactive, and the language’s name was chosen for marketing synergy with Java despite having very different designs.

CSS A stylesheet language used to describe the presentation of a document written in HTML, controlling layout, colors, and fonts.

Developed by the W3C and first released in 1996, CSS was authored by Håkon Wium Lie and Bert Bos. It separates style from content, enabling responsive designs that work across devices. Today it’s supported by every modern browser and underpins frameworks like Bootstrap. Fun facts: CSS 3 introduced modules such as Flexbox and Grid, radically changing layout capabilities, and the “cascading” rule resolves conflicts by specificity and source order.

HTML The standard markup language for creating web pages, defining the structure and content of a document.

Tim Berners‑Lee wrote the first version of HTML in 1991 while at CERN. It provides the skeleton of web pages, using tags to denote headings, paragraphs, links, and more. HTML5, standardized in 2014, added native multimedia, canvas, and semantic elements, making it the backbone of modern web applications. Notable tidbits: the original HTML had only 18 tags.

Markdown A lightweight markup language with plain-text formatting syntax, often used for formatting README files and writing on platforms like GitHub.

John Gruber created Markdown in 2004 with help from Aaron Swartz. It lets writers produce formatted text using simple symbols (e.g., * for italics, # for headings). Its simplicity led to widespread adoption on GitHub, Reddit, and many documentation sites. Interesting facts: many flavors exist (CommonMark, GitHub‑Flavored Markdown), and the language was deliberately designed to be readable as plain text.

JSON A lightweight data interchange format that is easy for humans to read and write, and easy for machines to parse and generate.

Douglas Crockford formalized JSON in 2001 as a subset of JavaScript object literals. It quickly became the lingua franca for APIs because of its compactness and native support in most languages. Today it’s used in web services, configuration files, and NoSQL databases. Fun fact: despite its JavaScript roots, JSON is language‑agnostic and defined by RFC 8259.

XML A markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable.

XML was released as a W3C recommendation in 1998, building on SGML. It provides a flexible way to structure data with custom tags, making it popular for document exchange, configuration, and SOAP web services. While its verbosity led to JSON’s rise for APIs, XML remains vital in industries like publishing and finance. Notable tidbits: XML supports namespaces to avoid tag collisions, and XSLT can transform XML into HTML or other formats.
